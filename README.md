# EV Remote

A personal Android app for the electric Opel Mokka-e: battery, charging, pre-heating, trips and car location.

**[⬇ Download the latest version (EvRemote.apk)](https://github.com/Vilsab94/Ev-Remote/releases/latest/download/EvRemote.apk)**

## Installation

1. Download `EvRemote.apk` on your phone and install it (allow installing from unknown sources).
2. Sign in with your myOpel account.
3. For remote control: Settings → Security → SMS code and the car's security code.

The app notifies you when a new version is available.
